
# Sales Analysis Using SQL

## Business Problem
The objective of this project is to analyze sales data and generate key business insights related to revenue, profit, and customer performance.

## Dataset
- Sales transaction data
- Includes order date, product, quantity, price, and region

## Tools Used
- SQL Server
- SQL (Joins, CTEs, Window Functions)

## KPIs
- Total Revenue
- Total Profit
- Average Order Value
- Month-over-Month Growth

## Key Insights
- Identified top-performing regions
- Detected declining products
- Highlighted seasonal trends

## Files
- `sales_analysis.sql` – main SQL script
